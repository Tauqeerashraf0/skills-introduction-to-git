🛠️ The Commands Used
For future reference, here are the essential Git commands used to set up and push files:

Bash
# Clone the repository (if working locally)
git clone https://github.com/Tauqeerashraf0/skills-introduction-to-git.git

# Create a new directory and navigate into it
mkdir READMe
cd READMe

# Stage the changes
git add .

# Commit with a message
git commit -m "feat: added READMe directory and first file"

# Push to the remote repository
git push origin main
💡 Key Takeaways
Version Control: Tracking changes step-by-step makes collaboration and rollback seamless.

Commit Messages Matter: Clear messages help maintain clean repository history.

Keep Building: Every complex project starts with a single file.
